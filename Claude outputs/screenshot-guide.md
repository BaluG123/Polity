# Play Store Screenshot Guide — Rajakiya

Play Store allows 2–8 screenshots. Recommended: **6 screenshots**.
Size: **1080 x 1920 px** (9:16 portrait) or **1920 x 1080 px** (16:9 landscape).
Use **portrait (1080x1920)** — it performs better on mobile listings.

## Design Tips for Screenshot Frames

- **Background:** Use the navy gradient (#081A33 → #12335F) behind the phone mockup
- **Caption font:** Bold, white text with gold (#C79A3E) accent on keywords
- **Phone frame:** Use a clean device mockup (Pixel 8 or generic Android)
- **Consistency:** Same background gradient, same caption font, same phone frame across all 6
- **Gold accent bar:** Add a thin gold line at top/bottom of each screenshot for brand consistency

## Free Tools to Create Framed Screenshots

1. **Screely** (screely.com) — simple browser/phone frames
2. **AppMockUp** (app-mockup.com) — Play Store-ready templates
3. **Figma** — use a free screenshot template (search "Play Store screenshot template")
4. **Canva** — search "App Store screenshot" templates, customize with your brand colors

---

## Capture Checklist

- [ ] Run the app on a clean Pixel emulator (no notification bar clutter)
- [ ] Set language to English for screenshots
- [ ] Take one set in Light mode, one in Dark mode (use dark mode for Screenshot 6)
- [ ] Ensure real content is showing (not placeholder/lorem text)
- [ ] Hide the navigation bar if possible for cleaner captures
- [ ] Resolution: exactly 1080x1920 or higher (Play Store rejects below 320px on any side)
